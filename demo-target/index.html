XSS Demo Target

Two endpoints to test the scanner against. One is vulnerable, one is safe.

⚠️ Vulnerable endpoint

Reflects the query parameter directly into HTML — no encoding.

/api/echo?query=hello

Test with: /api/echo?query=hello

✅ Safe endpoint

Reflects the query parameter as HTML-encoded text.

/api/safe?query=hello

Test with: /api/safe?query=hello

These endpoints are intentionally built to demonstrate XSS detection. Do not use this code in production.
