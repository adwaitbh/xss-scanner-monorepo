# xss-scanner-web

Frontend for [xss-scanner](https://github.com/adwaitbh/xss-scanner) — a reflected XSS scanner that discovers parameters, injects payloads, and confirms execution in a headless browser.

**Live:** https://xss-scannerweb.vercel.app

## Stack
- Next.js 15
- Tailwind CSS
- lucide-react

## Run locally
\`\`\`bash
npm install
npm run dev
\`\`\`

Open http://localhost:3000.

## Backend
The scanner API: [github.com/adwaitbh/xss-scanner](https://github.com/adwaitbh/xss-scanner)

## Legal
Only scan systems you own or have explicit permission to test.
